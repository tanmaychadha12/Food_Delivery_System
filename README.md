# 🍴 Food Delivery System (Python + SQLite)

## 📌 Project Overview
This is a simple **Food Delivery System** implemented in **Python** with **SQLite database** for order management.  
It allows users to register, view restaurants, browse menus, place orders, and check their order history.

---

## ⚙️ Features
- User Registration  
- View Restaurants  
- View Restaurant Menus  
- Place Orders  
- Track Order History  
- Data stored using SQLite (no external setup needed)

---

## 🛠️ Technologies Used
- Python
- SQLite
- Pandas
- Numpy
- Matplotlib

---

## 🎯 Project Objective

The objective of this project is to build a basic food delivery management system using Python and SQLite while applying database management, data analysis, and visualization concepts to analyze customer orders and sales trends.
